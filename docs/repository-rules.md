# 公开仓库文件限制

仓库：`luopancas-bit/english-sdudy`

本仓库用于远程协作和代码审查，不是服务器数据备份。它是公开仓库，因此采用“公开代码、私有内容、私有运行数据”的边界。

## 可以提交

- TypeScript、React、CSS 和测试代码
- Dockerfile、Compose 模板和无秘密的示例配置
- 数据库 schema 与迁移
- 合成测试数据
- 架构、接口、部署和恢复说明
- 不含个人数据的设计概念与界面规范

## 禁止提交

| 文件或数据 | 原因 | 正确位置 |
|---|---|---|
| `.env`、AccessKey、密码、Cookie、证书私钥 | 泄露后可控制账号、DNS 或服务器 | 服务器 `/opt/server/configs/secrets/` |
| SQLite 数据库及 WAL/SHM | 包含账号、成绩、错题和会话 | `/data/share/apps-data/english-study/data/` |
| 跟读录音 | 属于个人声音与学习隐私 | `/data/share/apps-data/english-study/recordings/` |
| 用户书籍、阅读笔记与解析结果 | 可能含版权内容和个人阅读隐私 | `/data/share/apps-data/english-study-v2/reading/` 与 SQLite 数据库 |
| 备份、日志、统计导出 | 可能间接包含身份或令牌 | `/backup/` 与服务器日志目录 |
| 课文 PDF、单词表、课程音频 | 体积大且可能受版权限制 | 服务器私有内容目录 |
| 旧版 `app/` 与根目录 `public/` | 含旧实现及与私有课程耦合的资源，不属于重构后的公开边界 | 仅作本地迁移参考，完成切换后删除 |
| 牛津词典 SQLite/MDD 与提取音频 | 许可证与版权限制 | 服务器只读词典挂载 |
| 服务器 IP、SSH 密码和内部拓扑明细 | 扩大攻击面 | 本地离线运维文档 |

## 强制措施

1. `.gitignore` 默认排除上述目录和文件类型。
2. GitHub Actions 在提交和 PR 上运行密钥扫描、类型检查、测试和构建。
3. 生产环境只通过只读挂载取得私有课程和词典；运行数据使用独立可写卷。
4. 示例配置只允许占位值，不能包含可用凭据。
5. 发现秘密误提交时，必须先轮换秘密，再清理 Git 历史；仅删除当前文件不够。

## 远程协作约定

- 默认通过 `agent/*` 分支和草稿 PR 协作。
- 主分支必须保持可构建。
- 功能 PR 必须说明学习规则变化、数据迁移影响和验证方式。
- 改动掌握率、计分、复习周期或账号安全规则时，必须同时更新测试和文档。
