# 逐光英语发布验收清单

本清单用于每次课程内容或考核流程更新后的最终验收。自动化测试通过不等于真实 iPhone
麦克风权限和跨设备同步已经通过；涉及真实设备的项目必须由使用者勾选并记录日期。

## 1. 线上入口

- [ ] 在电脑浏览器打开正式 HTTPS 入口，地址栏显示受信任的连接。
- [ ] 在 iPhone Safari 打开同一入口，不使用内网 `8787` 地址进行录音验收。
- [ ] 登录后刷新页面，昵称、课程进度和今日计划仍然存在。
- [ ] 退出再登录，学习记录和复习任务仍然存在。

## 2. 前三课完整流程

对第 01、02、03 课分别完成一次检查：

- [ ] 打开课程正文、逐句学习和核心词汇。
- [ ] 进入正式考核，听力、精读、跟读、听写四个维度均出现。
- [ ] 听力题只播放目标单词或短语，不播放整段课程音频。
- [ ] 听写题从当前显示句子的起点播放，不回到第一句；切换题目后从新句子起点播放。
- [ ] 第一次播放显示播放图标，播放完成后显示重播图标；`0.75× / 1× / 1.5× / 2×` 均可选择。
- [ ] 跟读题允许录音后回放；停止录音并显示“录音已保存”后才能进入下一题。
- [ ] 跟读题不要求在手机上再次输入朗读文本。
- [ ] 完成整组后才显示结果；未达标仍可继续下一课，不被锁定。
- [ ] 正式成绩、错题和复习任务在返回今日学习后可见。

## 3. iPhone 与电脑同步

- [ ] 在 iPhone 的第 01 课考核中完成至少一道题，填写答案并保存一条有效录音。
- [ ] 直接关闭页面或返回今日学习。
- [ ] 在电脑登录同一账号，重新进入同一考核，当前题号、答案和录音凭据已恢复。
- [ ] 在电脑提交后，用 iPhone 刷新并确认结果页与学习记录一致。
- [ ] 重新录音后，旧录音凭据被替换；未保存的新录音不能提交。

## 4. 单词记忆与音标

- [ ] 单词记忆和生词本都显示美式、英式音标。
- [ ] 点击音标或口音标记可以播放对应读音；缺失读音明确显示“待补全”，不猜测填入。
- [ ] “训练这一组”完成键入、纠错、提交和统计闭环。
- [ ] 单词未完成不会阻止下一课；只有正式考核或到期复习能推进间隔任务。
- [ ] 章节正式考核结果写入数据库，并生成或更新 `1、3、7、14、30` 天复习计划。

## 5. 阅读、翻译与数据保护

- [ ] 阅读中双击/长按单词，查词结果显示音标和可用读音。
- [ ] 翻译整句只返回译文；网址、缩写、数字和长句不被错误截断。
- [ ] 翻译重复请求命中缓存；质量检查失败的结果不会进入可复用缓存。
- [ ] 用户书籍、录音、课程内容、词典资源和数据库不出现在公开 Git 仓库。
- [ ] 使用最近备份在隔离临时容器中执行 SQLite 完整性检查，结果为 `ok`；不得把备份直接覆盖生产数据库。
