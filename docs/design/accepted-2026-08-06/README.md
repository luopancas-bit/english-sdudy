# 2026-08-06 响应式重构设计基准

本目录中的四张视觉稿已经由项目负责人确认，作为本轮 Web 与 iPhone
响应式重构的视觉基准：

- `dashboard-desktop.png`：桌面端应用外壳与今日学习页。
- `dashboard-mobile.png`：iPhone 今日学习页与四入口底部导航。
- `assessment-desktop.png`：桌面端沉浸式正式听力考核。
- `assessment-mobile.png`：iPhone 正式听力考核与安全区操作栏。

## 不可改变的产品规则

- 保留现有数据库、课程内容、学习记录、评分规则和 API。
- 单词学习优先但不限制继续学习；正式掌握必须通过考核或系统测试。
- 正式考核整组结束后才显示答案与结果。
- 听力题播放独立单词或短语音频，不得退回整课音频。
- 桌面端使用侧栏；移动端主导航固定为今日学习、单词记忆、复习、我的。
- 学习与考核进入沉浸页，隐藏普通导航。

## 设计系统

- 背景：暖象牙白；正文：深森林绿；优先级与进度：克制的赭金色。
- 中文衬线字体只用于主要标题，控件和正文使用系统无衬线字体。
- 细边框、轻阴影、6–10px 圆角；避免满屏卡片和装饰性标签。
- 移动端触控目标不小于 44px，并支持 iPhone 安全区和 200% 文字缩放。
- 正式考核不通过颜色或图标提前透露答案。
