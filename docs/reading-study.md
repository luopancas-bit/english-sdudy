# 阅读学习

“阅读学习”与“今日学习”“课程地图”同级，但它是自由阅读区：阅读时长、完成进度、查词、翻译、
笔记和生词来源都不会写入课程掌握率、解锁条件、正式考核或间隔复习队列。只有用户把单词加入既有
生词本后，才会进入原来的单词训练流程。

## 书籍来源与格式

- 本地导入：EPUB、PDF、TXT、MOBI、AZW/AZW3、FB2、HTML、Markdown、DOCX、RTF。
- 精选书库：内置 12 本 Project Gutenberg 公版英文原著 EPUB，随 worker 镜像部署并在本地解析，不依赖服务器访问 Gutenberg；用户点击“加入书架”后即可开始阅读。
- 在线搜索：Project Gutenberg OPDS；用户确认“加入书架”后才下载。
- PDF 第一版保留文本顺序并提供阅读排版，不对扫描图片自动 OCR。
- DRM/密码保护文件允许上传，但系统只标记为“受保护”，不破解、不移除 DRM，也不提供绕过工具。

## 阅读与学习工具

- 桌面端双击英文词、移动端长按（浏览器上下文手势）打开查词卡片。
- 查词优先复用本地版本化音标与读音库，释义不足时再查询在线词典。
- 可把原形、书名、章节、原文句子和位置作为出处加入既有生词本。
- 所选英文句子可调用管理员配置的在线翻译 API；每用户每天最多 100 次，按句子哈希缓存，
  不保存 API 密钥到客户端，也不记录完整请求日志。
- 阅读偏好、章节进度、划线、笔记、书签与保存的译文按账号同步；最近打开的书会写入浏览器
  IndexedDB，断网时可继续阅读已缓存内容。

## 隐私、额度和存储

- 用户上传的书默认为私有；管理员任务页只显示书籍 ID、状态、进度、错误码和时间，不显示正文。
- 默认每人 100 本、总计 5 GiB、单本 300 MiB。
- 原始文件和解析结果位于 `READING_DIR`，生产环境挂载到宿主机
  `/data/share/apps-data/english-study-v2/reading/`，不得提交到 Git。
- 主 API 不安装电子书转换器；`office-english-study-reader-worker` 独立运行 Calibre/Poppler，
  与主服务共享 SQLite 队列和阅读数据卷。

## 功能开关与恢复

`READING_ENABLED=false` 会停用全部阅读 API，入口会显示模块不可用；`READING_UPLOAD_ENABLED=false` 只关闭用户上传。
关闭功能不会删除阅读表或数据卷。部署、备份和回滚命令见 `docs/deployment-runbook.md`。
