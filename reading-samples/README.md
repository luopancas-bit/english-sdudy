# 内置英文阅读样本

此目录收录 EnglishStudyV2 精选书库使用的 12 本无 DRM 英文公版 EPUB。文件按 Project Gutenberg 书号对应，取自 Project Gutenberg 或 Standard Ebooks 的公开 EPUB 下载，仅作为应用内置阅读样本使用。

部署时，阅读 worker 会从这里复制样本到阅读数据目录并解析为章节清单。服务器不需要访问外部书源，样本也不会自动计入课程考核。
